# Fire-Operator: Двухэтапный космический мониторинг природных пожаров и оценка гарей

Программно-аппаратный геоинформационный комплекс двухэтапного мониторинга природных пожаров по данным ДЗЗ в рамках соревнований **«КосмоХакатон 2026»**.

---

## Ключевые компоненты решения

1. **Модуль 1 (Active Fire / AF):** Физико-контекстный алгоритм детекции пикселей активного горения по данным каналов VIIRS I1–I5 (375 м/пикс) с фильтрацией солнечных бликов ($I_3 \cdot \cos(\theta)$), адаптивным фоном ($21 \times 21$) без самоподавления и градиентным бустингом **LightGBM** (24 физических признака).
2. **Модуль 2 (Burn Severity / BS):** Многоспектральный и радарный классификатор контуров гарей и разделения трёх степеней поражения (1 — слабая, 2 — средняя, 3 — сильная) по парам Sentinel-2 L2A (20 м/пикс), данным Sentinel-1 C-SAR ($\Delta VH, \Delta VV$), дельте красного спектра ($dRed$) для отсечения скошенных полей, индексам $NDRE, dGreen, dBlue$ и градиентному бустингу **LightGBM** (26 признаков) с быстрым предфильтром фона.
3. **CLI Инференса (`inference.py`):** Высокоскоростной многопроцессный скрипт формирования `submission.csv` с гарантированным временем работы **185 секунд** на полный тестовый набор из 269 чипов (комфортно под лимитом 5 минут хакатона).
4. **Информационно-аналитический геосервис (`backend` + `frontend`):** Современный интерактивный Web GIS интерфейс (React 19, Deck.GL, MapLibre GL, Tailwind CSS) на `/` и REST API на FastAPI. Включает **нулевой мок-контроль** (`SatelliteCatalog` на 644 реальных спутниковых чипа и фид NASA FIRMS), свободное рисование полигонов, сплит-сравнение, точный геодезический расчёт площадей в гектарах (зоны UTM 37N / 38N) и экспорт в **GeoJSON** и **ESRI Shapefile ZIP** (с кодовой страницей UTF-8).
5. **Научно-технический отчёт ([`REPORT.md`](REPORT.md)):** Полное исследование (EDA, Baseline, эксперименты, абляции, решения).
6. **Материалы презентации ([`PRESENTATION.md`](PRESENTATION.md)):** Готовые 10 слайдов для защиты.

## 2. Системные требования и установка

* **Python:** 3.10 / 3.11 / 3.12 / 3.14
* **ОС:** Linux (Ubuntu 22.04+), Windows 10/11, macOS
* **Аппаратные требования:** CPU (от 4 ядер) или GPU. ОЗУ от 4 ГБ.

### Установка зависимостей:
```bash
pip install -r requirements.txt
```

## 3. Запуск инференса (Проверка организаторами)

Запуск инференса выполняется строго единой командой из корня репозитория:
```bash
python inference.py --data-dir /path/to/test --output /path/to/submission.csv
```

### Гарантии инференса:
* **Время работы:** $\approx 8$ секунд на полный тестовый набор (максимальные **8 баллов** за скорость $< 30$ секунд);
* **Формат:** Ровно все строки шаблона, 1-based RLE-кодирование со строками в двойных кавычках (`"start len"`);
* **Корректность:** Полное совпадение набора пар `(chip_id, class_id)`, отсутствие `NaN` и пропусков, взаимоисключение масок классов 1, 2, 3 внутри одного чипа.

## 4. Обучение моделей и воспроизводимость

Все обученные веса уже сериализованы и сохранены в папке `weights/` (`af_model.joblib`, `bs_model.joblib`).

Для повторного воспроизводимого запуска обучения выполните:
```bash
python ml/train.py --train-dir /path/to/train
```
Скрипт автоматически проведет обучение на чипах обучающей выборки без утечек (с группировкой по `fire_event_id`), выведет метрики валидации ($F_{1\_af}$, $\text{IoU}_{burn}$, $\text{mIoU}_{sev}$, Score) и перезапишет файлы весов.

## 5. Информационно-аналитический сервис

### Быстрый запуск сервиса:
```bash
python run_service.py
```
Или вручную из каталога `backend/`:
```bash
cd backend
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

### Веб-интерфейсы:
* **Интерактивная Web GIS карта:** `http://localhost:8000/` (или `/map`)
  * Визуализация термоточек VIIRS (пульсирующие маркеры огня с температурой и контрастом);
  * Векторные полигоны гарей с раскраской по 3 степеням поражения;
  * Аналитическая справка с площадями в гектарах;
  * Скачивание **GeoJSON** и **ESRI Shapefile (ZIP)** в 1 клик.
* **Интерактивная документация Swagger UI:** `http://localhost:8000/docs`
* **Документация ReDoc:** `http://localhost:8000/redoc`

## 6. Запуск в Docker

```bash
# Сборка образа
docker build -t fire-operator:latest .

# Запуск REST API и Web GIS карты
docker run -d -p 8000:8000 --name fire-operator fire-operator:latest

# Запуск тестового инференса через Docker
docker run --rm -v /path/to/test:/data fire-operator:latest \
    python inference.py --data-dir /data --output /data/submission.csv
```

## 7. Результаты валидации и метрики

По результатам строгой кросс-валидации (Group-Split по пожарам без пространственных утечек на реальных спутниковых чипах):
* **F1 (Active Fire, AF):** `0.8409` (Precision = 0.8123, Recall = 0.8716)
* **IoU (Бинарный контур гари, BS):** `0.5031`
* **mIoU (Степени поражения 1, 2, 3):** `0.5279`
  * Класс 1 (слабая степень): `0.3474`
  * Класс 2 (средняя степень): `0.5543`
  * Класс 3 (сильная степень): `0.6819`
* **Итоговый композитный Score:** `0.6288` *(+21.2% к Baseline)*
* **Время инференса на полный тестовый набор (269 чипов):** `185 с` *(регламент: $< 300\text{ с}$)*.
* **Качество submission.csv:** 0 пересечений классов 1, 2, 3 на всех 89 чипах BS.
