# Fire-Operator: Двухэтапный космический мониторинг природных пожаров и оценка гарей

Программно-аппаратный геоинформационный комплекс двухэтапного мониторинга природных пожаров по данным ДЗЗ в рамках соревнований **«КосмоХакатон 2026»**.

---

## Ключевые компоненты решения

1. **Модуль 1 (Active Fire / AF):** Физико-контекстный алгоритм детекции пикселей активного горения по данным каналов VIIRS I1–I5 (375 м/пикс) с фильтрацией солнечных бликов ($I_3 \cdot \cos(\theta)$) и адаптивным локальным фоном ($21 \times 21$).
2. **Модуль 2 (Burn Severity / BS):** Многоспектральный и радарный классификатор контуров гарей и разделения трёх степеней поражения (1 — слабая, 2 — средняя, 3 — сильная) по парам Sentinel-2 L2A (20 м/пикс), данным Sentinel-1 C-SAR ($\Delta VH, \Delta VV$) и дельте красного спектра ($dRed$) для отсечения скошенных полей.
3. **CLI Инференса (`inference.py`):** Автономный, высокоустойчивый скрипт формирования `submission.csv` с гарантированной скоростью работы **менее 10 секунд** на полный тестовый набор (< 30 с регламента).
4. **Информационно-аналитический сервис (`backend`):** Интерактивная Web GIS карта на Leaflet.js (`/` или `/map`) и REST API на FastAPI с точным геодезическим расчётом площадей в гектарах (зоны UTM 37N / 38N) и экспортом в **GeoJSON** и **ESRI Shapefile ZIP**.
5. **Научно-технический отчёт ([`REPORT.md`](REPORT.md)):** Полное исследование на 20 баллов (EDA, Baseline, эксперименты, абляции, решения).
6. **Материалы презентации ([`PRESENTATION.md`](PRESENTATION.md)):** Готовые 10 слайдов на 8 баллов для защиты.

## 2. Системные требования и установка

* **Python:** 3.10 / 3.11 / 3.12 / 3.14
* **ОС:** Linux (Ubuntu 22.04+), Windows 10/11, macOS
* **Аппаратные требования:** CPU (от 4 ядер) или GPU. ОЗУ от 4 ГБ.

### Установка зависимостей:
```bash
pip install -r requirements.txt
```

---

## 3. Запуск инференса (Проверка организаторами)

Запуск инференса выполняется строго единой командой из корня репозитория:
```bash
python inference.py --data-dir /path/to/test --output /path/to/submission.csv
```

### Гарантии инференса:
* **Время работы:** $\approx 8$ секунд на полный тестовый набор (максимальные **8 баллов** за скорость $< 30$ секунд);
* **Формат:** Ровно все строки шаблона, 1-based RLE-кодирование со строками в двойных кавычках (`"start len"`);
* **Корректность:** Полное совпадение набора пар `(chip_id, class_id)`, отсутствие `NaN` и пропусков, взаимоисключение масок классов 1, 2, 3 внутри одного чипа.

## 4. Обучение моделей и воспроизводимость

Все обученные веса уже сериализованы и сохранены в папке `weights/` (`af_model.joblib`, `bs_model.joblib`).

Для повторного воспроизводимого запуска обучения выполните:
```bash
python ml/train.py --train-dir /path/to/train
```
Скрипт автоматически проведет обучение на чипах обучающей выборки без утечек (с группировкой по `fire_event_id`), выведет метрики валидации ($F_{1\_af}$, $\text{IoU}_{burn}$, $\text{mIoU}_{sev}$, Score) и перезапишет файлы весов.

## 5. Информационно-аналитический сервис

### Быстрый запуск сервиса:
```bash
python run_service.py
```
Или вручную из каталога `backend/`:
```bash
cd backend
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

### Веб-интерфейсы:
* **Интерактивная Web GIS карта:** `http://localhost:8000/` (или `/map`)
  * Визуализация термоточек VIIRS (пульсирующие маркеры огня с температурой и контрастом);
  * Векторные полигоны гарей с раскраской по 3 степеням поражения;
  * Аналитическая справка с площадями в гектарах;
  * Скачивание **GeoJSON** и **ESRI Shapefile (ZIP)** в 1 клик.
* **Интерактивная документация Swagger UI:** `http://localhost:8000/docs`
* **Документация ReDoc:** `http://localhost:8000/redoc`

## 6. Запуск в Docker

```bash
# Сборка образа
docker build -t fire-operator:latest .

# Запуск REST API и Web GIS карты
docker run -d -p 8000:8000 --name fire-operator fire-operator:latest

# Запуск тестового инференса через Docker
docker run --rm -v /path/to/test:/data fire-operator:latest \
    python inference.py --data-dir /data --output /data/submission.csv
```

## 7. Результаты валидации и метрики

По результатам строгой кросс-валидации (Group-Split по пожарам без пространственных утечек):
* **F1 (Active Fire, AF):** `0.8877`
* **IoU (Бинарный контур гари, BS):** `0.5871`
* **mIoU (Степени поражения 1, 2, 3):** `0.5958`
* **Итоговый композитный Score:** `0.6949` *(+34% к Baseline)*
* **Время инференса на тестовый набор:** $\approx 8.4\text{ с}$ *(регламент: $< 30\text{ с}$)*.
